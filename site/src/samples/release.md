# 0.1.0

First public release.

- Rendered preview and raw Markdown in one block
- Copy the original source, with a clipboard fallback
- Word wrap toggle while viewing the source
- GitHub-flavored Markdown through `remark-gfm`
- External links open in a new tab
- Theme with CSS variables, including light and dark
- Pass remark plugins, rehype plugins, and custom renderers

ESM only, with TypeScript types. Peer dependency: React 18 or newer.
